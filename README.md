# _Lingula_ genome project - R script

This repository contains an R script that was used to generate figures for our _Lingula anatina_ genome paper.

Reference:

Lewin TD, Sakagami T, Shimizu K, Kao LJ, Chiu YL, Liao IJY, Chen ME, Hisata K, Endo K, Satoh N, Holland PWH, Wong YH, Luo YJ (2026) Brachiopod genome unveils the evolution of BMP signalling in bilaterian body patterning. Nature Communications 17, 3856.
